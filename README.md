# Ananya's 21st Birthday

A small countdown-first birthday microsite for Ananya's 21st birthday on August 26, 2026.

## Run locally

```bash
npm install
npm run dev
```

## GitHub Pages

Create a public repository named `ananya-birthday` under `Not-TheA-man`, push this project to its `main` branch, and enable GitHub Pages with **GitHub Actions** as the source. The included workflow will publish the site at `https://not-thea-man.github.io/ananya-birthday/`.

The page uses the local timezone-aware birthday moment configured in `src/main.js`. Before the birthday, only the countdown is available. At midnight on August 26 in India, the memory journey unlocks.
